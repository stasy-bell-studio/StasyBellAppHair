# Stasy Bell OS 2.0 (Android)

Нативное Android-приложение (Kotlin + Jetpack Compose) для владелицы студии ухода и восстановления волос **Stasy Bell** (Санкт-Петербург, ул. Ольги Берггольц, д. 9, корп. 2).

## Основные возможности (16 экранов)
- **Вход и безопасность (01, 16):** авторизация владельца с защитой от перебора, шифрование токенов сессии в Android Keystore (30 дней), опциональная биометрия, управление активными сессиями, требование HTTPS для боевого сервера.
- **Главная / «Сегодня» (02):** KPI записей на день, **фактически полученные деньги** (строго ручная касса), загрузка дня (`—` в выходной), ближайшие визиты, быстрые действия.
- **Календарь и график (03, 04, 05, 06, 15):** режимы День / Неделя / Месяц, рабочие окна и перерывы, блокировки времени, ручная запись без обязательного телефона, сохранение снимка цены/длительности, проверка пересечений `[startsAt, occupiedUntil)` с учётом буфера (`409 Conflict`), перенос, статусы, защищённое мягкое удаление, восстановление с проверкой конфликта и журнал событий.
- **Клиенты и каталог услуг (07, 08, 09):** поиск, редактирование, история визитов, связанные ручные поступления, отдельный блок архивных записей из Excel; управление прайсом, длительностями и буферами без перезаписи исторических визитов.
- **Фактическая касса (10, 11):** ручной ввод доходов и расходов в целых копейках, график по неделям, защита от дублей (`Idempotency-Key`), **сторно** (один раз, без удаления оригинала), версионированное закрытие и переоткрытие месяца с причиной. Завершение визита никогда не создаёт выручку автоматически.
- **Склад и материалы (13, 14):** учёт в `г / мл / шт` с точностью `0,001`, критические остатки, приход/списание с запретом ухода в минус, независимость от кассовых расходов.
- **Отчёты и архив Excel (12):** раздельная аналитика фактической кассы, производственных показателей визитов и изолированного архива Excel с очередью сверки непривязанных визитов.

## Режимы работы
- **Демо (Room):** автономная локальная SQLite-база с синтетическими данными (логин `nastya` / пароль `stasy2026`), явно помеченная бейджем `Демо`.
- **Сервер FastAPI (HTTPS):** типизированный REST-клиент (Retrofit + Kotlinx Serialization), совместимый с единым API и PostgreSQL.
